# おくすりカレンダー

服薬タイミングを Google カレンダーに登録する Chrome 拡張機能です。
**注意事項は予定の「説明（詳細）」欄に書き込まれる**ので、カレンダーの通知を開けばその場で確認できます。

**Google Cloud の設定や API キーは不要**で、読み込んだらすぐ使えます。

---

## インストール

1. Chrome で `chrome://extensions` を開く
2. 右上の **デベロッパーモード** をオンにする
3. **パッケージ化されていない拡張機能を読み込む** をクリックし、このフォルダを選ぶ
4. ツールバーの 💊 アイコンから使えます

以上です。Google アカウントの連携も不要です。

---

## 2つの登録方法

入力内容は同じで、出口が2つあります。用途で使い分けてください。

### ① カレンダーで開く（手軽）

Google カレンダーの**予定作成画面が入力済みの状態で開きます**。内容を確認して **保存** を押すだけです。

- 服用タイミングの数だけタブが開きます（1日3回なら3タブ）。1つずつ保存してください
- 保存先のカレンダーは、その画面で選べます
- ログイン中の Google アカウントのカレンダーに保存されます

### ② ICSファイルを書き出す（まとめて登録向き）

標準形式のカレンダーファイルを書き出します。**すべての予定を1回で取り込めます。**

1. **ICSファイルを書き出す** を押して保存
2. [Google カレンダー](https://calendar.google.com/) を開く
3. 右上の ⚙️ → **設定** → 左メニューの **インポート / エクスポート**
4. 書き出したファイルを選び、取り込み先カレンダーを指定して **インポート**

通知（○分前）の指定が反映されるのは、こちらの方法だけです。

---

## 使い方

1. **薬の名前**（必須）と、必要なら **用法・用量** を入力
2. **服用タイミング** をプリセット（起床時 / 朝食後 / 昼食後 / 夕食後 / 就寝前）から選ぶ。複数選べます。時刻とラベルは後から編集でき、「＋ 時刻を追加」で自由な時刻も足せます
3. **注意事項** を入力 — ここに書いた内容が予定の詳細欄に入ります。上のボタンで定型文（食後30分以内 / グレープフルーツジュース不可 / 眠気注意 など）をワンクリック追記できます
4. **開始日 / くり返し / 服用期間** を指定
   - くり返し：毎日 / 1日おき / 毎週（曜日指定）/ 1回だけ
   - 期間：日数指定（例：7日分）/ 終了日指定 / 期限なし
5. **登録内容のプレビュー** で、実際に入る文面を確認
6. **カレンダーで開く** か **ICSファイルを書き出す** を押す

### 登録される予定の例

| 項目 | 内容 |
|---|---|
| タイトル | `💊 ロキソニン錠60mg（朝食後）` |
| 日時 | 2026/09/10 8:00〜8:10（毎日・7日分） |
| 説明（詳細） | 下記のとおり |

```
【用法・用量】
1回1錠

【注意事項】
食後30分以内に服用
グレープフルーツジュースと一緒に飲まないこと
服用後に眠気が出ることがあるため運転注意

― おくすりカレンダーで登録 (ロキソニン錠60mg)
```

予定は「空き時間」扱いで登録されるため、カレンダー上で「予定あり」とは判定されず、他の予定調整の邪魔になりません。

### お薬リスト

**この内容をお薬リストに保存** を押すと、薬ごとの設定を保存できます。**お薬リスト** タブの **読み込む** でフォームに復元されるので、同じ薬をまた処方されたときに入力し直す必要がありません。同じ薬名で保存すると上書きされます。

## できること・できないこと

| | カレンダーで開く | ICSファイル |
|---|---|---|
| 事前設定 | 不要 | 不要 |
| 保存の手間 | 予定ごとに「保存」を1クリック | 1回のインポートで全件 |
| 注意事項を詳細欄へ | ✅ | ✅ |
| くり返し・期間 | ✅ | ✅ |
| 通知（○分前）の指定 | ❌ カレンダー既定の通知が付く（保存画面で変更可） | ✅ |
| 保存先カレンダーの指定 | 保存画面で選ぶ | インポート画面で選ぶ |
| 予定の色の指定 | ❌（保存後に変更可） | ❌（保存後に変更可） |

拡張機能から予定を**削除**することはできません。登録済みの予定は Google カレンダー側で削除してください（くり返し予定は「これ以降のすべての予定」でまとめて消せます）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張機能の定義 |
| `calendar-utils.js` | 予定データの生成（URL組み立て・RRULE・ICS） |
| `popup.html` / `popup.css` / `popup.js` | 入力フォームとお薬リストの UI |
| `icons/` | ツールバーアイコン |

---

## うまくいかないときは

| 症状 | 対処 |
|---|---|
| タブは開くがログイン画面になる | 開いた画面で Google にログインしてください。ログイン後、同じ内容の作成画面に進みます |
| 複数アカウントで別のカレンダーに入ってしまう | 開いた予定作成画面の右上でアカウントを切り替えるか、ICSファイル方式を使ってください |
| ICSをインポートしても予定が見当たらない | インポート時に選んだカレンダーが非表示になっていないか確認してください |
| 毎週指定で開始日がずれる | 開始日が選んだ曜日でない場合、最初の該当曜日から始まるよう自動で調整しています（仕様です） |
| 変更が反映されない | `chrome://extensions` で再読み込み（⟳）してください |

---

## プライバシー

- 入力内容とお薬リストは、この PC の Chrome のローカルストレージ（`chrome.storage.local`）にのみ保存されます
- 拡張機能自体は外部と通信しません。Google カレンダーへの送信は、開いたタブ上でご自身が「保存」を押したときだけ発生します
- 権限は `storage`（入力内容の保存）と `downloads`（ICSファイルの書き出し）のみです

---

## 注意

この拡張機能は服薬の記録・リマインドを補助するツールであり、医療上の助言を行うものではありません。用法・用量や注意事項は、必ず処方箋・薬剤情報提供書の記載や、医師・薬剤師の指示に従って入力してください。
